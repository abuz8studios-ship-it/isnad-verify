# Isnad Verify — no lie, no omission
Public claim-verification recipe from ABUZ8. Every public claim carries a named chain: **witness → transmitter → gap**.
- **Witness**: ran it here, or fetched a named source this turn (URL/command named).
- **Transmitter**: who said it. Never upgrade their README into "we ran it."
- **Gap**: hiding a material fact (kitman) = a lie.
Ledger: every ship logs a status URL + proof. No URL = didn't happen.
